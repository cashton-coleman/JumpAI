# Support

Start with the [FAQ](FAQ.md) and [installation guide](skills/jumpai/references/installation.md).

For bugs, questions, or feature requests, search [GitHub Issues](https://github.com/cashton-coleman/JumpAI/issues) for an existing discussion, then open a new issue if needed.

For installation problems or bugs, include:

- Your Jump AI version or Git commit.
- Your operating system, whether you use WSL, and your Python version.
- Steps to reproduce the problem, expected behavior, and what happened instead.
- Relevant errors and output from `./install.sh doctor`, run from the Jump AI installation directory.

Remove credentials, tokens, private code, and other sensitive information before posting. Share only the details needed to understand the problem.

For feature requests, describe the task you want to accomplish and how the change would help.

Support is provided as time permits. Response times and fixes are not guaranteed.
